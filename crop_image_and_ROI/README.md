# 重建图像 ROI 与结果排版

对多个重建方法的结果图共用矩形框和箭头，批量保存画框原图与 ROI，并直接生成比较图，减少在 PPT 中逐张排列的工作。

## 启动

使用 Python 3.12 或更新版本，当前验证环境为 Python 3.14.7。Windows 安装 Python 时保留 Tcl/Tk 组件；依赖版本记录在 `requirements.txt`。

```powershell
python -m pip install -r requirements.txt
python crop_image.py
```

也可以双击 `main.bat`。启动失败时窗口会保留错误信息。界面使用标准库 tkinter；Pillow 用于常规图像与预览，NumPy、PyPNG、tifffile 用于保留 16 位图像数据。更新旧版后先重新安装 `requirements.txt`。

## 数值配置

所有可调的数值默认值集中在项目目录的 `config.json`，不需要修改 Python 代码。文件内有中文说明，修改后重启软件生效；JSON 不支持 `//` 注释，不要删除键名。非法数值、拼错的键名或不完整的配置会明确报错。

| 分组 | 可配置内容 |
| --- | --- |
| `window` | 默认/最小窗口宽高、屏幕留白、DPI 尺寸基准 |
| `editor` | 默认线宽、箭头大小、增减步长、最小头部大小、尖端外延、箭头形状比例、虚线长度/间隔、最小绘制尺寸、预览留白 |
| `layout` | 每行数量、间距、边距、原图宽度、ROI 初始宽高、导出 DPI、排版预览留白；保留旧版倍数/标题字段用于兼容 |
| `limits` | 参数允许范围、最大导出像素数；超限仍然拒绝导出，不会自动缩小图片 |
| `timing` | 界面任务检查、图像刷新、排版预览的时间间隔（毫秒） |
| `ui` | 控件宽度、列表行数、字体大小、间距、面板比例、拖动滚动范围、坐标小数位数等 |

例如将 `editor.arrow_size` 改为 `30` 可改变新箭头的默认大小；`editor.selection_dash` 为 `[5, 3]` 表示实线 5 像素、间隔 3 像素；`layout.columns` 决定新项目默认每行数量。默认配置保持原版箭头的形状和大小规则。

界面输入仍可调整当前项目。具体标注坐标、已有标注的大小和项目排版值由“保存项目”写入项目 JSON，打开项目时优先恢复项目值；`config.json` 控制新建时的默认值。坐标索引、文件格式位深、90° 旋转等算法或格式常量不是可调参数，仍保留在代码中。原有 `colors.txt` 继续配置常用颜色。

## 画框与箭头

1. 点击“打开图像组”，多选同一组重建结果。
2. 选择“矩形 ROI”后拖动画框，可创建多个 ROI。切换到“箭头”后拖动，起点是尾部，终点是箭头尖端。
3. 标注对整组图像生效。不同分辨率采用相对坐标映射，要求素材具有相同的视野和内容配准。
4. 点击右侧标注，可修改坐标、颜色、线宽、箭头头部大小。坐标以原图像素输入；矩形和箭头统一输入起点 x/y/宽/高。箭头的宽、高分别为终点相对起点的水平、垂直位移，可为负数，表示向左、向上。箭头形状和大小沿用原版：默认头部 20 预览像素，尖端沿终点外延 3 预览像素，短箭头不自动缩小头部；“箭头增大/减小”每次调整 2，减小到 10 为止。新画箭头记录绘制时的预览尺寸，导出时将完整箭头几何映射到原图，保证相对大小和位置一致。缩放窗口时已有箭头跟随图像缩放。上一版项目没有该尺寸记录时仍按其原图像素单位读取，避免静默改变已保存标注；编辑该箭头或点击增大/减小后采用旧版预览单位。
5. “导出原图和 ROI”会在选定目录内新建带时间戳的文件夹。`rectange/` 保存仅带矩形的原图；`roi-0/`、`roi-1/` 等保存仅带箭头的局部原始裁剪；`coordinates.json` 保存标注与参考尺寸。

支持反向画框、撤销、删除、90° 旋转，窗口大小改变不会改变标注。旋转同时变换标注坐标。Ctrl+O 打开图像，Ctrl+S 保存项目，Ctrl+Z 撤销最后一个标注。

选中标注后，在坐标输入框内按回车即可更新；顶部线宽和箭头大小输入框也支持回车应用。画图页可用方向键 ← / → 切换上一张 / 下一张，在文件列表、标注列表或页签栏获得焦点时同样有效。在输入框中编辑文字或数字时，左右键只移动光标；点击画布或切回画图页后恢复翻图。绘制过程中不响应翻图快捷键。

在标注列表中选中的 ROI 和箭头均显示为虚线，箭头头部显示虚线轮廓。点击图像中的空白、图像外背景、标注列表的空白或面板空白处，会取消全部标注选择；也可以按 Esc。点击坐标输入框和应用按钮会保留选择。虚线仅用于界面提示，导出图片中的标注保持实线。

矩形与箭头的**线宽统一使用参考原图像素**，预览与批量导出均使用同一换算规则；同样线宽不会再因标注类型不同而粗细不同。箭头头部大小和尖端外延继续使用原版的预览像素规则，与线宽分开计算。预览缩小时线条至少显示 1 像素，实际导出的线宽以源图像素换算后取整。旧项目中两类标注的线宽数值也直接按这一统一规则读取。

右下角显示当前文件列表，点击文件即可切换显示；可拖动条目或使用“上移 / 下移”调整顺序，上一张 / 下一张和生成的排版素材会同步使用新顺序。排序时会保持当前查看的文件及其对应的排版名称、ROI。点击“添加文件”可以中途补充同组图片，保留已有标注、旋转和当前画面，重复文件会自动跳过。添加后点击“生成 / 刷新排版素材”，新文件即可按已有标注生成原图和 ROI；文件顺序会随项目一起保存。“打开图像组”仍用于重新开始一组图片。

## 排列比较图

点击“生成 / 刷新排版素材”，自动进入“排列结果”。也可以直接导入以前导出的图片：

排版预览和导出图均不显示文件名称，也不留标题区域。生成后会按矩形 ROI 数量显示独立设置行，箭头不计入 ROI 数量。上方显示当前原图的原始宽、高，以及设置“原图宽度”后实际排版的宽、高，便于输入 ROI 尺寸。

每个 ROI 设置输出宽、高（像素），以及两组独立的**同侧边缘距离**：左右基准下拉框选择“左 / 右”，上下基准选择“上 / 下”，分别输入距离。距离以 ROI 输出区域的对应边缘和排版原图的同侧边缘计算：

| 选择 | 距离含义 |
| --- | --- |
| 左 | ROI 左边距离原图左边多少像素 |
| 右 | ROI 右边距离原图右边多少像素 |
| 上 | ROI 上边距离原图上边多少像素 |
| 下 | ROI 下边距离原图下边多少像素 |

例如选择“上、左”并填写上 10px、左 20px，ROI 的上、左边分别距原图上、左边 10px、20px；选择“下、右”并填写下 10px、右 20px，则 ROI 的下、右边分别距原图下、右边 10px、20px。距离为 0 时对应边缘对齐，正数向原图内侧，负数向外侧。允许图片重叠，程序不会自动移动输入的位置。设置在同组所有方法中共用，刷新素材和保存项目会保留这些设置。

默认宽、高取这一 ROI 在各张源图中裁剪尺寸的最大值，可在 `config.json` 的 `layout.roi_width`、`layout.roi_height` 设置初始值，0 表示自动读取。输出保持宽高比，在输入宽高形成的区域内居中留白；宽、高不能小于任一对应原始裁剪的尺寸。新建 ROI 默认从原图左上角向右展开：均以上、左为基准，上距为 0，第一个左距为 0，后续左距为前面 ROI 的宽度与当前间距之和。已手动调整或项目中保存的位置会保留。随后可输入任意边距；放到原图外侧时，合图会扩展画布以保留全部图片。更早版本的固定位置或方向偏移项目会自动换算为等效的“上、左”边距以保留已有位置。ROI 设置行较多时可使用右侧滚动条。

- “导入已有原图 / ROI”：选择已有图片。
- “导入结果文件夹”：读取目录内图片，识别旧版 `rectange/`、`roi-N/` 中同名图片并自动配成方法组。只选择结果目录，避免把其他图片一起导入。
- “追加图片（无 ROI）”：将残差图等独立图片加入当前排版，保留已有素材和 ROI 设置。附加图片不画框、不画箭头、不生成 ROI。可拖动排序、移除；刷新素材后仍保留，并随项目保存。
- 图片列表下方的“添加空白图”：插入一个透明占位，没有选中条目时加到列表末尾，选中时加在最后一个选中条目后面。空白图占用一个图片/方法位置，可拖动排序、批量移除，刷新素材与保存/恢复项目后仍保留，无需另建空白图片文件。占位仅预留尺寸和位置，区域内会显示排版背景或下方图片；与其他图片重叠时不会遮挡。点击重叠区域会选中实际图片，需要选择空白占位时可从列表选择。尺寸跟随第一张主体图；全是附加图时以第一张实际图片为准。没有实际图片时使用配置 `layout.blank_width`、`layout.blank_height`（默认 512 × 512）。空白图不会参与附加图片的批量旋转，也不影响 8/16 位图像数据或 ICC 配置。

排版页中新导入的原图、ROI、结果文件夹及追加图片，会自动沿用“画框与箭头”页当时的累计旋转角度，先按 90° 的整数倍无插值旋转，再参与排版缩放。已有素材不重复旋转；追加图仍可批量调整方向。项目分别记录导入时的角度与追加图片的最终角度，恢复时不会叠加当前编辑页角度；旧项目保持原有方向。源文件不被覆盖。

附加图片的输出宽、高自动统一为当前第一张主体图片的排版尺寸；分组模式以第一组原图为基准，自由混排以第一张非附加图片为基准。只有附加图片时，以第一张附加图为基准。改变排序或原图输出宽度后，尺寸会同步重新计算。宽高比不一致时直接按目标宽、高 resize，不留白；使用 Lanczos 缩放，每次从保留的原始图像生成，不反复缩放预览或中间结果。输入图片本身不被覆盖。

排版列表支持 Ctrl 点击多选不连续条目、Shift 点击选择连续范围；Ctrl+A 或“全选”按钮选择所有条目，“仅选附加图”一次选中所有残差图等独立图片，“取消选择”或列表内 Esc 清空选择。分组模式选择方法组，自由混排选择单张图片。

需要旋转多张残差图时，点击“仅选附加图”，再点击“批量左转 90°”或“批量右转 90°”。也可手动多选其中几张；全选中包含重建原图和 ROI 时，批量旋转只处理附加图片。旋转在后台执行，完成后保留多选状态，可连续点击到 180°、270°；列表会标明各图当前方向。先对保留的原始像素做无插值转置，再按首图尺寸 resize，不修改重建原图、ROI 或磁盘源文件。旋转状态会在刷新素材及项目保存恢复后保留。

画图页的“添加文件”用于扩充共用标注的重建图组；排版页的“追加图片（无 ROI）”用于残差图等独立结果。

| 模式 | 每行数量含义 | 排列效果 |
| --- | --- | --- |
| 按 ROI 相对位置（默认） | 方法组数 | 每个 ROI 按与原图同侧边缘的左右、上下距离放置 |
| 原图上 / ROI 下 | 方法组数 | 每组原图在上，多个 ROI 依次在下 |
| 原图左 / ROI 右 | 方法组数 | 每组原图在左，多个 ROI 依次在右 |
| 原图一行 / ROI 分行 | 方法组数 | 一行原图，随后每个 ROI 各占一行，方法列对齐 |
| 自由混排 | 图片张数 | 所有图片按顺序自动换行，可逐张调整 |

在左侧列表拖动，或将预览图片拖到另一张图片上即可调整顺序；多选后拖动其中一个选中条目或其预览，可将所有选中条目一起移动，保留相互顺序。“上移 / 下移”和“移除所选素材”也对全部选中条目生效。双击单个条目可修改列表中的识别名称，名称不会显示在图中。可设置间距、边距、背景和 DPI。ROI 尺寸设置对所有模式生效；同侧边缘距离只在“按 ROI 相对位置”模式下生效。

“导出排版 PNG / TIFF”直接生成一张比较图，可整张插入 PPT。预览上方显示最终像素尺寸。修改标注后需刷新素材，程序会阻止导出旧标注的排版图。

点击排版预览中的任意原图、ROI、追加图片或空白图，预览上方会显示该图片的“距左 / 距上”，单位是最终导出图的像素。修改后点击“应用位置”或按回车即可移动。移动原图时，同组全部 ROI 同步平移，保留各 ROI 与原图的相对位置及已经单独调整的距离；选中 ROI、追加图片或空白占位时只移动它本身。重叠区域优先选中最上层实际图片，蓝框显示本次移动涉及的图片，不会导出。列表仍按方法组选择，但预览中可单独选中组内的某个 ROI。

距离可以输入负数。一旦某张图片位于画布左侧或上侧之外，会将全部图片统一平移，以所有图片最左、最上的边缘为新原点，并重新显示非负坐标；不会裁掉负坐标处的图片。例如某图移至 `(-20, -10)` 且它在最左上方时，该图的新坐标为 `(0, 0)`，其他图片统一向右 20px、向下 10px。画布尺寸随新的图片范围计算，保留配置的右、下边距。后续位置修改直接基于新的原点。

位置微调会随图片排序、素材刷新和项目保存恢复保留；修改每行数量等自动排版参数时，仍会自动重排并保留各图片的微调。“恢复所选位置”取消当前图片的微调，恢复原图时会同时恢复同组 ROI；“全部恢复自动”清空全部微调。这里只平移图片，不缩小、拉伸或改变图像位深。

设置“每行张数/组数”为 N 后，点击“设置前 N 项方法名”，为**排版列表前 N 项**填写实际方法名，例如 `FBP`、`SART`、`Ours`。对话框会预览默认导出文件名，例如 `comparison__FBP__SART__Ours.png`，方法名顺序对应从左到右的方法列，文件名中不添加列编号；素材不足 N 项时使用实际数量。分组模式每项是一组方法，自由混排每项是一张图片；同一方法的原图和 ROI 共用名称。其余行按相同方法顺序排列时，可直接用这个文件名辨认各列。

方法名随对应素材移动，导出时重新读取当前列表前 N 项，改变 N 后无需清空已填名称；刷新素材和保存/恢复项目会保留名称。方法名仅显示于列表、写入文件名，不加入图片，也不改变图像处理。未填写时沿用素材名称，Windows 文件名禁用字符会替换为下划线；文件名过长会提示填写较短简称，长度限制可在 `limits.filename_max_chars` 配置。保存对话框中仍可手动修改文件名；重新打开图像组或替换导入素材会清空方法名。

“保存项目”记录源文件路径、标注、旋转、素材顺序、名称、附加图片和排版参数，下次用“打开项目”恢复。项目不嵌入图像，请保留原位置的源文件。重新导入素材会替换当前排版素材。

## 图像质量

- 预览与导出分离。ROI 直接从经过方向校正的原图裁剪，不使用缩小后的预览。
- 原图与 ROI 默认不重采样，无损 PNG 导出；排版支持 PNG 或无损压缩 TIFF（8 位用 LZW，16 位用 Deflate）。原始文件不会被修改，JPG 源图不会再经过 JPG 有损编码；已经存在的 JPG 压缩损失无法恢复。
- “原图宽度”为 0 时保留每张原图原始尺寸；ROI 逐个输入输出宽、高。保持宽高比，只允许保持或放大，不允许缩小源图或 ROI。
- 按要求新增的附加图片会统一 resize 到首张主体图尺寸，允许缩小和改变宽高比；缩小会减少像素。输出仍使用无损 PNG/TIFF，不增加有损编码压缩。
- ROI 放大默认使用像素复制，整数比例时每个原始像素被完整复制；可选 Lanczos 平滑放大，但插值会改变像素值，不会增加真实细节。
- 箭头边缘单独做抗锯齿，大小、位置与箭头头部仍沿用原有几何。生成的 ROI 保留原始背景和箭头坐标，排版放大时先放大背景，再按最终输出尺寸重绘箭头，避免把小图中的阶梯锯齿一起放大。只混合箭头覆盖的边缘像素，其他源像素不变；8 位和 16 位均支持。可在 `editor.arrow_antialias_scale` 调整边缘采样倍率（默认 4，设为 1 关闭），`editor.annotation_tile_size` 控制绘制分块大小。更新后请重新生成素材；已导入的旧 ROI 位图不含箭头坐标，不能自动重绘。
- DPI 仅设置物理尺寸信息，不会凭空增加细节，也不会降低像素数。透明通道与同一 ICC 配置保留；混合不同 ICC 配置的素材会提示先统一色彩空间，避免静默改变颜色。
- 支持常见 8 位灰度、RGB、RGBA、调色板图像，以及无符号 16 位 PNG、TIFF 灰度/RGB/RGBA 图像。16 位图像单独保留全精度数据，矩形、箭头、旋转、ROI 裁剪和导出均不经过 8 位中间图；彩色标注输出为 16 位 RGBA，未标注处保留原始数值。8 位、16 位混排时，8 位通道按数值乘 257 提升到 16 位，整体保存为 16 位 PNG/TIFF。屏幕预览采用固定 0–65535 到 0–255 映射，不回写原始数据、不自动调整窗宽窗位。浮点、有符号整数、CMYK 等其他数据仍拒绝自动转换，避免丢失精度。
- 最终合图默认超过 1.5 亿像素会提示减少素材或调整 ROI 尺寸，可在 `limits.max_output_pixels` 配置上限；不会通过降低分辨率强行导出。大型素材的内存需求仍取决于源图总量。
